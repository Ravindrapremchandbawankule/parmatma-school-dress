# Parmatma Ek School Dress

## Setup & Run

### Backend
```bash
cd server
npm install
npm run dev
```
Server runs on http://localhost:5000

### Frontend
```bash
cd client
npm install
npm run dev
```
Frontend runs on http://localhost:3000

## API Endpoints
- GET  /api/products         - All products
- GET  /api/products?category=Boys  - Filter by category
- POST /api/enquiry          - Submit enquiry
- GET  /api/enquiries        - View all enquiries
